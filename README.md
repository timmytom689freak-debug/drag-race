# RuPaul's Drag Race Simulator

A lightweight browser-based simulator inspired by fan-made Drag Race simulators.

## Run locally

```bash
python3 -m http.server 4173
```

Then open http://localhost:4173.

## Gameplay

1. Add at least 6 queens (or load the sample cast).
2. Start the season.
3. Run episodes until one queen remains and wins the crown.
